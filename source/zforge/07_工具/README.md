# 测试入口

在 ZForge 项目根目录（本文件的上一级）执行。

## 自动化回归

```bash
python -m unittest discover -s 07_工具 -p "test_*.py"
node 07_工具/test_frontend.cjs
```

Python 的 unittest discovery 运行 46 项测试，覆盖账号池、租约、登录录入、项目隔离、任务恢复、工作流和 SQL 约束。Node 脚本执行 6 组前端检查。测试使用临时目录和模拟数据，不需要真实账号，不主动采集外站。

## 手动外站验收

`test_e2e.py` 是真实采集脚本，直接运行时会调度采集器、使用本机账号池并写入本地数据库。
`test_http_e2e.py` 是针对正在运行的本地服务的手动 HTTP 验收，直接运行时可能派发真实采集任务。

这两个文件没有 unittest 用例，discovery 不执行它们的命令行入口。需要做真实采集时再阅读脚本并单独运行；当前发布验证没有执行外站采集。

运行产生的数据库、编译缓存和日志均为本机文件，不提交仓库。公开副本无需保留这些输出。
