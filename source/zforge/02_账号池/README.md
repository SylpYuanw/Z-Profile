# 账号池

账号统一保存在 `数据/accounts.db`；同站点可建立多个命名池。一个账号可以加入多个池，
凭据、登录状态、额度及任务占用仍按同一账号 ID 计算。密钥在项目外的 `%APPDATA%\ZForge\`。

## 网页操作

1. 双击项目根目录的 `启动.bat`，等待「已就绪」和自动打开网页。
2. 左侧「采集 → 账号池」，选择站点并新建用途池，例如「淘宝日常采集」。
3. 推荐「打开登录页添加账号」：填写管理手机号及可选名称，在独立 Edge 窗口完成扫码或手机登录。
   系统检测登录 Cookie 后自动加密保存，无需寻找或导出 Cookie。手机号仅用于本地管理，不改变网站绑定信息。
   密码、短信验证码只在官方网页输入。完整手机号通常不能从平台获取，不能还原掩码。
   名称默认手机号；「账号资料 / 改名」可修改显示名，详情仍保留手机号和内部账号 ID。
   第一期逐个账号登录，完成后可「继续添加下一个账号」，暂未提供批量手机授权队列。
   「文件导入（高级）」仍支持 Cookie 数组或含 `cookies` 数组的 JSON，每次最多 20 文件、合计 2 MB。
4. 同一账号加入另一同站点池时，使用「加入已有账号」。重复导入身份会被拒绝。
5. 「重新登录」或「文件更新」只能更新相同平台身份的账号，不会用另一个账号覆盖旧账号；使用中的账号不可更新或移出。
6. 采集页选择兼容账号池；工作流每步可独立选池，使用「仅保存配置」保存，之后直接运行。

「池设置」可重命名、切换选号策略、停用及设置站点默认池。默认池停用前需先设置另一个默认池。
「移出本池」只删除成员关系，保留凭据、历史及其他池关系。没有成员的账号仍可从「加入已有账号」找回。

## 状态与使用规则

- **登录状态**：导入后为「待检测」。Cookie 时间戳已过期或已知失效时为「过期待检测」，不会参与领取。
  本地时间戳未到期不代表网站仍接受登录态。「检测有效」须来自采集器明确的站点检测结果。
- **轮换状态**：健康、冷却、封禁、停用。健康不等于网站登录有效；停用不会因导入新凭据而自动启用。
- **额度**：领取一次计一次，回报不重复计数。跨池共用额度；默认每日 200 次。
- **占用**：一个任务保持同一账号，采集器完成清理后才释放。跨池也不能并发重复领取。
  90 秒租约、25 秒续约；异常进程退出后到期回收，续约失败会请求取消任务。
- **选号**：优先今日使用最少，或优先最久未使用。只在指定池中选择，不偷偷跨池回退。
- **无号**：明确失败；前端当前池无可领取账号时引导检查账号状态和导入，不启动采集。

只有明确账号相关的结果回报会影响健康状态；解析、入库错误及零匹配结果不能直接当作账号失败。
已知过期的淘宝账号保持原凭据和历史。本轮仅在隔离库验证官方登录页打开和取消，未完成真实账号扫码授权。
B站当前路线为 Selenium 搜索列表 + HTTP 详情 API，匿名运行，不绑定账号池。

## 导入安全与备用命令

浏览器仅上传用户选定的本地文件，不读取或展示 Cookie 内容。后端校验站点域名、身份和关键 Cookie，
加密后保存；接口、任务记录与页面均不返回明文凭据。原始导出文件不复制到项目中。
保管好原始文件和项目外密钥。

网页是推荐入口。备用命令必须明确提供文件，不再默认覆盖「主号」，也不会试领账号或伪造网站连通性记录：

```powershell
python 07_工具/import_taobao_account.py --file "D:\凭据\账号.json" --pool 2 --label "备用号"
python 07_工具/import_taobao_account.py --file "D:\凭据\账号.json" --pool 2 --update-account-id 1
```

池 ID 与账号 ID 以网页实际显示为准。新增和更新均经过相同身份校验。
单账号网页登录已接入，等待上限 10 分钟；取消、关闭窗口或超时不保存未完成的凭据。
只检测到关键 Cookie 时记录「待检测」，不声称网站登录验证成功。批量授权队列、独立登录检测与独立运行配置模板仍待做。

## 实现与验证

`server/core/accounts.py` 管理账号健康、额度与历史；`account_groups.py` 管理池、成员、导入和租约。
`TaskRunner` 将任务池绑定落到实际领取；工作流步骤与任务历史持久保存池 ID 和实际账号 ID。
`browser_login.py` 管理网页登录状态与浏览器清理；`browser_runtime.py` 与采集器共用兼容 Edge 驱动缓存，首次无缓存时限制驱动准备等待。
旧账号仅首次迁移至站点默认池；之后移出的成员不会因重启自动加回。

在项目根目录运行 `python -B -X utf8 07_工具/test_account_pools.py`，使用临时库验证迁移、导入、
隔离、占用、释放和持久化，不访问真实采集站点。
